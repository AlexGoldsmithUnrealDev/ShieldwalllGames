Vitus · Design playbook 02

Homepage hierarchy & navigation

Both concepts use Iron & Ink. They deliberately differ in density, narrative and the timing of their first software demonstration. All UI imagery is illustrative.

How they differ

DecisionConcept AConcept B
First impressionEmotional and cinematicProduct-focused
Hero visualWorld illustration + lore windowsLarge application interface
Homepage featuresThree chaptersSix compact tabs
Audience journeysThree editorial cardsFour solution cards
Page rhythmBig immersive transitionsCompact modules
Best strengthBrand identityProduct clarity
Biggest riskFeature depth too hiddenLess distinctive opening

Suggested navigation architecture

Primary: Features, Who it's for, Showcase, Pricing, Download.
Secondary: Vitus AI, Maps & History, Writing Desk, Roadmap, Guides, Support.
Company: Shieldwall Games, Contact, Privacy, Terms.

Do not try to give all ten+ destinations equal priority in the main navigation. Reserve the dropdown or mega-menu for the secondary destinations.

Suggested homepage compromise

Use A's atmospheric opening with B's interactive six-tab feature hub, then B's role cards, a single strong ownership/proof section and a focused conversion section. This would create a clearer hierarchy while keeping Vitus visually distinct.

Content and assets still needed

  • Actual logo/emblem assets and final font licences.
  • One finished demonstration world with consistent names and histories.
  • Real, brief captures: map editor, lore entry, writing desk, timeline, relationship view, local files.
  • Final pricing, download and platform claims from the latest versioned product inventory.
  • Separate mobile composition for the hero and feature previews.

Acceptance gates

The approved structure must work at 1440px, 1024px, 768px and 390px; have keyboard-operable navigation and tabs; respect reduced motion; avoid fabricated product claims; and load without depending on external image files.

No live website has been changed. This standalone HTML is an exploration for approval.
