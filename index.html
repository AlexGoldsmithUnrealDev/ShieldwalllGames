How we work

Built by makers, for makers.

Shieldwall Games is a small independent studio. We build the tools we needed and couldn't find, then we share them. Mimir came from the problem of keeping large fictional worlds coherent while building our own games.

We care about ownership, useful depth, and tools that earn their place in a creator's workflow. Mimir keeps local work local by default, while optional AI, collaboration, and hosting are there when the project actually needs them.
