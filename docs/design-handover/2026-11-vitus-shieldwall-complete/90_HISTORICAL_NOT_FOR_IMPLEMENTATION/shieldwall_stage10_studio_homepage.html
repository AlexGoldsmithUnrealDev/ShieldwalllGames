02 / How we work

Built by makers.
For makers.

Shieldwall Games is an independent studio. We create the tools we wanted to use ourselves and build worlds intended to be explored, played and remembered.

We're interested in the work behind a great fictional setting: its history, relationships, rules and consequences. Vitus grew from that need. Ashborn puts the same thinking to work in a game.
